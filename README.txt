PUMALA - Web App

Isi:
- index.html        = aplikasi PUMALA
- manifest.webmanifest = konfigurasi agar bisa dipasang sebagai web app/PWA
- sw.js             = cache offline saat sudah di-host
- README.txt        = petunjuk singkat

Cara mencoba:
1. Buka index.html di Chrome untuk penggunaan lokal.
2. Untuk web online, upload seluruh isi folder ini ke hosting yang mendukung HTTPS.
3. Data aplikasi pada versi ini masih tersimpan di browser (localStorage).
   Artinya data belum menjadi database cloud dan belum otomatis tersinkron
   antar-HP/perangkat.
4. Gunakan menu Backup untuk menyimpan salinan data JSON.

Menu PUMALA:
- Mie Get / Nyemek Ori - Rp10.000
- Mie Get / Nyemek + Baso / Sosis - Rp12.000
- Mie Get / Nyemek + Baso + Sosis - Rp13.000
- Pesanan tambahan/manual dengan nama, harga, dan Qty

Fitur:
Dashboard, Kasir, Stok/Bahan, Pemasukan, Pengeluaran, Laporan,
Delivery, Backup/Import, dan Export CSV.
